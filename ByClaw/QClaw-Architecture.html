理解层 (Understanding Layer) — LLM 多模型路由
Gateway LLM Proxy 模块负责请求路由、超时管理和多模型调度

OpenClaw 内核

开源 AI Agent 平台，广泛的生态覆盖
  • HTTP SSE 流式推理
  • 多模型路由与负载均衡
  • 工具调用与 Skill 编排
  • 多频道消息路由（微信/Telegram/Slack）
  • 插件化 Skill 系统
  • OpenAI 兼容 API (/chat/completions)

Hermes Agent 内核

持续学习与持久化记忆，macOS 独占支持
  • Python 3.11 运行时
  • 持久化记忆系统（情境/语义/动态调度）
  • 会话级状态管理与幽灵会话清理
  • /v1/responses 端点 + 流式输出
  • Prompt Inspector 工具链
  • 自动 Agent 同步（SOUL.md）

// 前端 WS 连接配置（从 renderer bytecode 提取） const options = { url: "ws://127.0.0.1:19789", // 本地 Gateway token: "dev-test-token", // 认证 Token clientId: "openclaw-control-ui", // 客户端标识 clientVersion: "1.0.0", mode: "webchat", // 或 "ui" autoReconnect: true, }; // 后端选择（应用层标识） sa(["openclaw", "hermes"]); // 双核枚举 const sj = "hermes_default"; // 默认 Hermes Agent ID
关键结论： 双内核共用同一个 Gateway WS 长连接，不是各自独立连接。前端只连 ws://127.0.0.1:19789，由 Gateway 内部 LLM Proxy 模块根据请求类型路由到 OpenClaw 引擎或 Hermes 进程。后端选择是应用层概念（qclaw_backend），不是连接层概念。
